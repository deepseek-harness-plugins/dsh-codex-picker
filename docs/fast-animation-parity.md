# 闪电加速动效对照

参考用户提供的 Codex 截图与 2026-10-20 本机客户端的静态界面资源：`impl-6a63a3972d45.js`、`impl-9597edf4b611.css`、`app-primary-71492d0e9e92.css`。本插件独立实现动画，闪电开关只控制视觉状态。

| 部分 | 对照参数 |
| --- | --- |
| 闪电按钮 | 32 × 32px 点击区域、26 × 26px 悬停区域、7px 内圆角、16px 图标；关闭时空心，开启时实心，最高档使用紫色。 |
| 加速粒子 | 14 个粒子沿整条轨道从右向左匀速穿越，基准周期 1.9 秒，速度分散在 80%–120%。 |
| 粒子外观 | 3px 基础直径，缩放 0.5–0.95，透明度 0.4–1，纵向分布在轨道的 12%–88%。 |
| 粒子错峰 | 相邻粒子约错开 136ms；开启时预先铺满整条轨道的运动相位，最左端立即有粒子，菜单重开继续显示相同的流动状态。 |
| 裁剪 | 运动路径始终按完整轨道计算，已填充范围之外不可见；切档只改变裁剪范围，不改变粒子速度。 |
| 开启圆点过渡 | 800ms 缩小至 75%；延迟 50ms 后用 1150ms 左移 85px；延迟 700ms 后用 500ms 淡出。 |
| 关闭圆点过渡 | 350ms 恢复尺寸并从右侧 10px 处归位，200ms 淡入。 |
| 粒子层淡入／淡出 | 普通档开启 80ms、关闭 250ms；最高档开启 250ms、关闭延迟 100ms 后淡出 300ms。 |
| 最高档粒子交接 | 开启时原有漂浮粒子延迟 200ms 后左移 110px，延迟 1 秒后淡出；关闭时从右侧 28px 处用 500ms 回位、淡入。紫色底层保持连续。 |

减少动态效果时停用流动粒子和圆点过渡。菜单重开不重复播放闪电开启过渡，也不会触发最高档气泡扩散。

自动验证覆盖普通档与最高档开启后 250ms 内左端可见粒子、整条轨道的单向匀速运动、圆点过渡、关闭回位、菜单重开、减少动态效果，以及不调用模型保存接口、不增加请求加速参数。
